Dans ce projet nous devons réaliser un "Web blog ".


# Définition 

Tout d'abord nous allons définir ce que signifie "Web Blog" :

>Un "Web blog " est un type de site Internet particulier qui peut être présenté comme une
sorte de journal intime publié sur la Toile, et accessible aux internautes du monde entier.
Il existe beaucoup de "moteurs de blogs" à l'extérieur, comme WordPress et Blogger,
mais dans ce projet, vous allez réaliser votre propre blog en utilisant le HTML et le CSS.
