# Projet-Web-blog-de-CRAVELLO.B-et-ROSOLI.Q

Dans ce projet, nous devons réaliser un **Web Blog**.

---

## Définition

Tout d'abord, nous allons définir ce que signifie **« Web Blog »** :

> Un « Web Blog » est un type de site Internet particulier qui peut être présenté comme une sorte de journal intime publié sur la Toile, et accessible aux internautes du monde entier.

Il existe beaucoup de moteurs de blogs, comme **WordPress** et **Blogger**, mais dans ce projet, nous allons réaliser notre propre blog en utilisant le **HTML**, le **CSS**, le **JavaScript** et le **PHP**.

### HTML

**HTML** signifie *HyperText Markup Language*.
> C'est un langage utilisé pour **créer et structurer le contenu d'une page Web**.

### CSS

**CSS** signifie *Cascading Style Sheets*.
> C'est un langage utilisé pour **mettre en forme et personnaliser l'apparence d'une page Web**.

### JavaScript

> **JavaScript (JS)** est un langage utilisé pour **rendre une page Web interactive et dynamique**.


---

## Objectif du projet

L'objectif est de créer un **site Web Blog** fonctionnel et responsive.

Le site devra contenir :

* **4 à 5 pages**
* Une page contenant du texte
* Une page contenant un formulaire de contact
* Une page contenant des images et des vidéos
* Une navigation entre les différentes pages
* Une version en **français et en anglais**
* Une apparence cohérente sur l'ensemble du site
* Un affichage adapté aux **PC, tablettes et smartphones**
